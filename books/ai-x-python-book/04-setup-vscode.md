これまでの章で、司令室（Windows Terminal）、アトリエ（`C:\dev`）、そしてツール格納庫（`C:\Miniforge3`）が準備できました。本章では、これらすべてを統括する万能ツール「**Visual Studio Code（VS Code）**」を導入し、プロフェッショナルな開発ワークフローを確立します。

ここでのゴールは、単にツールをインストールすることではありません。「**なぜ、そのように使うのか**」という理由を理解し、効率的で間違いのない開発スタイルを身につけることです。

## ステップ1: VS Codeをインストールする

Visual Studio Codeは、Microsoftが開発する、現代のソフトウェア開発で最も広く使われている高機能エディタです。豊富な拡張機能により、Python開発はもちろん、あらゆるプログラミング言語に対応できる高い柔軟性を誇ります。

これも`winget`コマンドを使って、ターミナルからスマートにインストールしましょう。

1.  **Windows Terminal**を開きます。
2.  以下のコマンドを入力し、Enterキーを押します。
    ```powershell
    winget install --id Microsoft.VisualStudioCode --exact
    ```
    インストールが完了したら、次に進みます。

## ステップ2: AI開発の「黄金律」 - 全てはターミナルから始める

ここで、今後のAI開発における最も重要な「作法」を学びます。それは、「**全ての開発作業は、ターミナルを起点に始める**」という黄金律です。

なぜこのルールがそれほど重要なのでしょうか？

Windowsはグラフィカルな操作に優れているため、多くの人はデスクトップのショートカットやスタートメニューからアプリケーションを起動します。しかし、開発においては、この習慣が「環境の迷子」を引き起こす最大の原因となります。

例えば、スタートメニューからVS Codeを直接起動した場合、VS CodeはどのPython環境（システムに元から入っていたものか、Miniforgeでインストールしたものか）を使えばいいのかを正しく判断できないことがあります。これにより、「ターミナルでは動くのに、VS Code上ではライブラリがないとエラーになる」といった、混乱を招く問題が発生しがちです。

この問題を解決するのが、ターミナル中心のワークフローです。

### 正しいワークフロー
1.  **Windows Terminal** を開く。
2.  `cd` コマンドで、作業したいプロジェクトのディレクトリ（アトリエ `C:\dev` 内のフォルダ）に移動する。
3.  必要に応じて `conda activate` コマンドで、そのプロジェクト専用のPython環境を有効にする。
4.  その場所、その環境で、**`code .`** というコマンドを実行してVS Codeを起動する。

この手順を踏むことで、VS Codeは「今いるディレクトリ」と「現在有効なPython環境」を正確に引き継いだ状態で起動します。結果として、環境の不整合によるエラーを未然に防ぎ、スムーズに開発に集中できるのです。

## ステップ3: 実際にやってみよう！VS Codeとの初回連携

それでは、この黄金律に従って、VS Codeと私たちの開発環境を初めて連携させてみましょう。

1.  **Windows Terminal**を開き、プロンプトの先頭に `(base)` が表示されていることを確認します。

2.  `cd` コマンドで、私たちのアトリエに移動します。
    ```powershell
    cd C:\dev
    ```

3.  アトリエの中心で、VS Codeを起動するコマンドを実行します。
    ```powershell
    code .
    ```
    :::message
    `code` はVS Codeを起動するコマンド、`.` （ドット）は「カレントディレクトリ（今いるこの場所）」を意味します。つまり、「今いる `C:\dev` フォルダをVS Codeで開いてください」という命令です。
    :::

4.  VS Codeが起動し、`dev` フォルダが開かれた状態になります。初回の起動時には、ウェルカムメッセージなどが表示されるかもしれません。

5.  **拡張機能のインストール**
    次に、Python開発を快適にするための拡張機能をインストールします。
    -   画面左側のアクティビティバーから、四角いブロックのアイコン（Extensions）をクリックします。
    -   検索ボックスに `Python` と入力し、Microsoft提供の「Python」拡張機能を探して「Install」をクリックします。
    -   同様に、`Jupyter` と検索し、Microsoft提供の「Jupyter」拡張機能もインストールします。

6.  **連携の最終確認**
    VS Code内のターミナルを開いて、全ての連携がうまくいっているか確認しましょう。
    -   メニューバーから `Terminal` > `New Terminal` を選択するか、ショートカットキー `Ctrl + @` を押します。
    -   画面下部にターミナルが表示されます。そのプロンプトの先頭に、Windows Terminalと同じく `(base)` が表示されていれば、連携は完璧です。

これで、あなたのPCには、司令室（Terminal）、アトリエ（`C:\dev`）、ツール格納庫（`C:\Miniforge3`）、そして万能ツール（VS Code）が完全に連携した、プロフェッショナルなAI開発環境が整いました。

お疲れ様でした。退屈に感じたかもしれない環境構築は、これで全て完了です。

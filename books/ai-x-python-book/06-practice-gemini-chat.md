前の章では、データからパターンを学習する「予測AI（機械学習）」を体験しました。この章では、現代のAI技術の主役とも言える「**生成AI**」に触れていきます。

Googleが開発した高性能な生成AIモデル「**Gemini**」と、APIを通じて対話するプログラムを作成します。APIとは、"Application Programming Interface"の略で、簡単に言えば「外部のソフトウェアやサービスと対話するための接続口」のことです。

この章のゴールは、あなたが入力したメッセージに対して、Geminiが人間のように自然な文章で応答してくれる、シンプルなチャットボットを自分のPC上で動かすことです。

## 0. 準備：プロジェクトの開始

今回も、黄金律に従ってプロジェクトを始めましょう。

1.  **Windows Terminalを開きます。**
    もし前のプロジェクトの環境`(handwriting-env)`が有効になっていたら、`conda deactivate`コマンドで一度`base`環境に戻っておきましょう。

2.  `cd C:\dev`でアトリエに移動します。

3.  このプロジェクト用の新しいフォルダ `gemini-chatbot` を作成し、そこに移動します。
    ```powershell
    mkdir gemini-chatbot
    cd gemini-chatbot
    ```

4.  このプロジェクト専用のConda環境`gemini-env`を作成し、アクティベートします。
    ```powershell
    conda create -n gemini-env python=3.10 -y
    conda activate gemini-env
    ```

5.  **Gemini APIをPythonから利用するためのライブラリをインストールします。**
    このライブラリは、`conda`の標準リポジトリには含まれていないため、Pythonの標準的なパッケージインストーラーである`pip`を使います。
    ```powershell
    pip install google-generativeai
    ```

6.  `code .`で、このプロジェクトをVS Codeで開きます。

## 1. APIキーの取得

Gemini APIを利用するには、認証のための「APIキー」が必要です。これは、あなたが正規の利用者であることを証明するための、あなた専用の秘密のパスワードのようなものです。

1.  Webブラウザで **Google AI Studio** にアクセスします。
    [https://aistudio.google.com/](https://aistudio.google.com/)

2.  Googleアカウントでログインします。利用規約などが表示されたら、内容を確認して同意します。

3.  画面が開いたら、左側のメニューにある「**Get API key**」をクリックします。

4.  「**Create API key in new project**」というボタンをクリックします。

5.  APIキーが生成され、長い文字列が表示されます。この文字列をコピーし、**誰にも見られない安全な場所（例えば、パスワード管理ツールや、一時的にメモ帳など）に保管してください。**
    :::warning
    **注意:** APIキーは、あなたのGoogleアカウントに紐付いた重要な情報です。絶対に他人に教えたり、GitHubなどの公開リポジトリにアップロードしたりしないでください。
    :::

## 2. 実装：PythonスクリプトでGeminiと対話する

今回はJupyter Notebookではなく、通常のPythonスクリプトファイル（`.py`ファイル）を作成します。

1.  **Python環境の選択**
    VS Codeの右下をクリックし、インタープリターがこのプロジェクトの `gemini-env` になっていることを確認・設定します。

2.  **スクリプトファイルの作成**
    VS Codeのエクスプローラーで、`app.py` という名前の新しいファイルを作成します。

3.  **コードの記述**
    `app.py`に以下のコードを記述します。

---
```python
import os
import google.generativeai as genai

# 1. APIキーの設定
#    安全のため、直接コードに書き込む代わりに環境変数から読み込むことを推奨しますが、
#    まずは動かすことを優先し、ここに直接キーを貼り付けます。
#    ただし、このファイルを他人に見せたり、公開しないように厳重に注意してください。
API_KEY = "ここに、先ほど取得したAPIキーを貼り付けます"
genai.configure(api_key=API_KEY)

# 2. モデルの選択
#    今回は、テキスト生成に特化した `gemini-pro` を使用します。
model = genai.GenerativeModel('gemini-pro')

# 3. チャットセッションの開始
chat = model.start_chat(history=[])

print("チャットボットを起動しました。'終了'と入力すると会話を終了します。")

# 4. 無限ループでユーザーからの入力を待つ
while True:
    user_input = input("あなた: ")
    
    # '終了'と入力されたらループを抜ける
    if user_input.lower() == '終了':
        print("チャットボットを終了します。")
        break
    
    # AIに応答を生成させる
    response = chat.send_message(user_input)
    
    # AIの応答を表示
    print(f"AI: {response.text}")

```
---
**コードの注意点:**
- `API_KEY = "..."` の部分に、先ほど取得したあなたのAPIキーを忘れずに貼り付けてください。

4.  **プログラムの実行**
    - VS Codeのターミナル（`Ctrl + @`で開く）が、`gemini-env`環境で`C:\dev\gemini-chatbot`にいることを確認します。
    - ターミナルで以下のコマンドを実行します。
    ```powershell
    python app.py
    ```

5.  **AIとの対話**
    「チャットボットを起動しました。」と表示されたら、成功です。
    `あなた:` の後に、何かメッセージを入力してEnterキーを押してみてください。しばらくすると、AIからの応答が返ってくるはずです。

    *   「こんにちは」
    *   「日本の首都はどこですか？」
    *   「面白いなぞなぞを一つ出して」

    様々な質問やお願いをしてみてください。まるで人間と会話しているかのような、自然で知的な応答に驚くことでしょう。会話を終えたいときは、「終了」と入力します。

## 【AIに聞いてみよう②】アイデア出し

あなたは今、基本的なチャットボットを動かすことに成功しました。しかし、このプログラムはまだ骨組みだけの状態です。ここから、どんな面白い機能を追加できるでしょうか？

自分だけで考えるのも良いですが、AIは優れたブレインストーミングの相手にもなります。私たちの家庭教師に、アイデア出しを手伝ってもらいましょう。

1.  Webブラウザで、Google Geminiなどの対話型AIサービスを開きます。

2.  AIへの質問（プロンプト）を入力するボックスに、以下のように相談を持ちかけます。

    **プロンプト例:**
    ```
    私は今、PythonとGemini APIを使って、シンプルなコンソールチャットボ-ットを作っています。
    現在の機能は、ユーザーが入力したメッセージにAIが応答するだけです。

    このチャットボットをより面白く、または便利にするための新しい機能を5つ提案してください。
    アイデアは、初心者でも実装できそうなレベルのものでお願いします。
    ```

3.  AIからの回答を見てみましょう。おそらく、以下のような創造的な提案をしてくれるはずです。

    *   **役割（ペルソナ）設定機能**: 最初に「あなたは猫のキャラクターになりきって話してください」のように役割を与えることで、AIの口調を変える機能。
    *   **しりとり機能**: ユーザーとしりとりができるゲームモードを追加する。
    *   **要約機能**: 長い文章を貼り付けると、その内容を3行で要約してくれる機能。
    *   **翻訳機能**: 「'Hello'を日本語に翻訳して」とお願いすると、翻訳してくれる機能。
    *   **会話履歴の保存機能**: 会話のやりとりをテキストファイルに保存し、後で読み返せるようにする機能。

AIは、私たちが思いつかないような視点からアイデアを提供してくれます。このように、開発の初期段階でAIと対話することは、プロジェクトの可能性を大きく広げるための強力な武器となります。

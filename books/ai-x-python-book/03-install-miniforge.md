司令室とアトリエの準備が整いました。次に行うのは、AI開発に不可欠な道具、すなわちPython本体と、そのエコシステムを管理するためのツールを収める「格納庫」の設置です。

この役割を担うのが「**Miniforge**」です。

## Miniforgeとは何か？

Miniforgeは、Pythonのディストリビューションの一つであり、特に科学技術計算やデータサイエンスの分野で広く利用されている`conda`というパッケージ管理システムを含んでいます。

`conda`を利用する主な利点は以下の通りです。

*   **環境の分離**: プロジェクトごとに独立したPythonの実行環境（仮想環境）を作成できます。これにより、「プロジェクトAではライブラリXのバージョン1.0が必要だが、プロジェクトBではバージョン2.0が必要」といった依存関係の衝突を完全に防ぐことができます。
*   **複雑なライブラリの容易なインストール**: データサイエンスで用いられるライブラリの中には、Python以外の言語（C++やFORTRANなど）で書かれたコードに依存しているものが多くあります。`conda`は、こうした複雑な依存関係を自動で解決し、コンパイル済みのバイナリパッケージをインストールしてくれるため、ユーザーは煩雑な設定作業から解放されます。

Miniforgeは、この`conda`システムを最小限の構成で提供する、軽量でクリーンなインストーラーです。

## ステップ1: Miniforgeインストーラーをダウンロード

まずは、Miniforgeのインストーラーをダウンロードします。

1.  Webブラウザで、Miniforgeの公式GitHubリポジトリにアクセスします。

    [https://github.com/conda-forge/miniforge](https://github.com/conda-forge/miniforge)

2.  ダウンロードセクションまでスクロールし、「Miniforge3-Windows-x86_64.exe」という名前のリンクを探します。これをクリックして、インストーラーをダウンロードしてください。通常は、PCの「ダウンロード」フォルダに保存されます。

## ステップ2: Miniforgeを専用の格納庫 `C:\Miniforge3` にインストールする

ここが、本書における**最も重要な手順の一つ**です。ダウンロードしたインストーラーを使ってMiniforgeをインストールしますが、そのインストール先をデフォルトの場所から、我々が意図したクリーンな場所に変更します。

1.  ダウンロードしたインストーラー（`Miniforge3-Windows-x86_64.exe`）をダブルクリックして起動します。

2.  ライセンスの同意などが表示されたら、内容を確認し、「Next」や「I Agree」をクリックして進めます。

3.  「Installation Type」では、「Just Me (recommended)」を選択したまま「Next」をクリックします。

4.  【**最重要ポイント】「Choose Install Location」という画面が表示されます。**
     <!-- ダミー画像URL。実際の書籍ではスクリーンショットを挿入 -->
    デフォルトでは、`C:\Users\YourName\miniforge3` のようなユーザーフォルダ内のパスが指定されています。これを**必ず変更**します。
    テキストボックス内のパスをすべて削除し、代わりに以下のパスを正確に入力してください。
    ```
    C:\Miniforge3
    ```
    これにより、日本語やスペースを含まない、Cドライブ直下のクリーンな場所にツールが格納されます。入力したら、「Next」をクリックします。

5.  「Advanced Installation Options」の画面では、**チェックボックスはすべて空のまま**にしておきます。特に「Add Miniforge3 to PATH...」にはチェックを入れないでください。これは後ほど、より安全な方法で設定します。「Install」をクリックすると、インストールが開始されます。

6.  インストールが完了したら、「Finish」をクリックしてインストーラーを閉じます。

## ステップ3: 司令室（PowerShell）と心臓部（Miniforge）を接続する

最後に、先ほど準備した司令室（Windows Terminal / PowerShell）から、設置したばかりのMiniforge（`conda`コマンド）を呼び出せるように、両者を接続します。

1.  **Windows Terminalを起動**します。（すでに開いている場合は、一度完全に閉じてから、再度起動してください）

2.  開いたPowerShellの画面に、以下のコマンドを正確に入力し、Enterキーを押します。
    :::message
    これは、「`C:\Miniforge3`の中にある`Scripts`フォルダの中の`conda.exe`というプログラムを使って、PowerShellのための初期化設定を行ってください」という命令です。
    :::
    ```powershell
    C:\Miniforge3\Scripts\conda.exe init powershell
    ```
    実行後、`"powershell" has been initialized.` といったメッセージが表示されれば成功です。

3.  【**超重要！】設定を反映させるため、もう一度Windows Terminalを完全に閉じてから、再度起動します。**

4.  新しく開いたターミナルのプロンプトを見てください。行の先頭に `(base)` という文字が表示されていれば、接続は完璧に成功しています。
    ```
    (base) PS C:\Users\YourName>
    ```
    この `(base)` は、現在`conda`の "base" という基本環境が有効になっていることを示しています。

これで、AI開発の心臓部となるツールの設置と、司令室との連携が完了しました。

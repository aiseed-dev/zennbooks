title: 第2章 司令室とアトリエの準備 (Windows Terminal & 開発ディレクトリ)

AI開発という航海に出る前に、まずは信頼できる船の「司令室（ブリッジ）」と、作品を生み出す「アトリエ」を準備します。この章で行う設定は、一見地味に見えるかもしれませんが、今後のすべての開発作業の快適性と安定性を左右する、非常に重要な土台となります。

## なぜ「フォルダの場所」が全ての基本なのか？

Windowsでプログラミングを始める際、多くの初学者が無意識のうちに陥ってしまう「罠」があります。それは、**日本語やスペース（空白）を含むフォルダパス**の問題です。

例えば、Windowsのデフォルト設定では、個人のファイルは以下のような場所に保存されることがよくあります。

`C:\Users\山田 太郎\Documents`

このパスには「山田 太郎」という日本語と、姓と名の間のスペースが含まれています。私たち人間にとっては自然な表記ですが、一部の開発ツールやライブラリは、こうしたマルチバイト文字やスペースを正しく解釈できず、予期せぬエラーを引き起こす原因となることがあります。

この問題を根本的に回避するため、私たちは開発に関わる全ての作業を、**パスに英数字しか含まない、浅い階層の専用ディレクトリ**で行うという、シンプルかつ強力なルールを採用します。

具体的には、
*   **ツールを置く場所（格納庫**）
*   **作品を置く場所（アトリエ**）
を明確に分離し、それぞれをCドライブ直下に作成します。この一手間が、将来の「原因不明のエラー」に悩まされる時間を劇的に減らしてくれるのです。

## モダンな司令室（Windows Terminal & PowerShell）をインストール

次に、コンピュータと対話するための「司令室」、すなわちターミナル環境を最新のものにアップデートします。Windowsには標準で「コマンドプロンプト」や「Windows PowerShell」が付属していますが、より高機能で開発者向けに設計された「**Windows Terminal**」と、最新版の「**PowerShell (7.x)**」を導入します。

これらを導入することで、タブ機能や見た目のカスタマイズ、コマンド入力の補完強化など、多くの恩恵を受けられます。

インストールには、Windowsに標準で搭載されているパッケージ管理ツール`winget`を使用します。これにより、Webサイトを探してインストーラーをダウンロードする手間なく、コマンド一つで安全にソフトウェアを導入できます。

1.  **管理者権限でターミナルを起動**
    スタートメニューを右クリックし、「ターミナル（管理者）」または「Windows PowerShell (管理者)」を選択します。

2.  **`winget`コマンドの実行**
    開いたターミナル画面に、以下のコマンドをコピー＆ペーストし、Enterキーを押します。
    ```powershell
    winget install --id Microsoft.WindowsTerminal --exact && winget install --id Microsoft.PowerShell --exact
    ```
    :::message
    `&&` は、左側のコマンドが成功したら、続けて右側のコマンドを実行するという意味です。これにより、Windows TerminalとPowerShellが連続してインストールされます。途中で確認メッセージが表示された場合は、`Y`キーを押して続行してください。
    :::

インストールが完了したら、一度開いているターミナルは閉じてください。

## あなたのAI作品が生まれるアトリエ `C:\dev` を作る

最後に、これからあなたのAIプロジェクト（ソースコード）が生まれる場所となる、専用のワークスペース（アトリエ）を作成します。

1.  **Windows Terminalを起動**
    スタートメニューから、先ほどインストールした「Windows Terminal」を探して起動します。
    :::tip
    今後、頻繁に使うことになるので、タスクバーにピン留めしておくことをお勧めします。
    :::

2.  **`mkdir`コマンドでディレクトリを作成**
    開いたターミナル（おそらくPowerShellのタブが開いています）に、以下のコマンドを入力し、Enterキーを押します。
    ```powershell
    mkdir C:\dev
    ```
    `mkdir`は "make directory" の略で、新しいディレクトリ（フォルダ）を作成するコマンドです。これで、Cドライブの直下に`dev`という名前のフォルダが作成されました。

3.  **`cd`コマンドでアトリエに移動**
    次に、作成したディレクトリに移動します。以下のコマンドを入力してください。
    ```powershell
    cd C:\dev
    ```
    `cd`は "change directory" の略です。コマンドラインの現在地が `C:\dev` に変更されたことを確認してください。プロンプト（`PS C:\Users\YourName>` のような表示）が `PS C:\dev>` に変わっていれば成功です。

ここが、これからあなたのAIプロジェクトが保管されていく、唯一の場所となります。

これで、司令室とアトリエの準備が整いました。次の章では、このクリーンな環境に、AI開発の心臓部となるMiniforgeを設置していきます。
